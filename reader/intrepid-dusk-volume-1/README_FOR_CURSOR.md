# Intrepid Dusk Volume 1 Reader Upload Package

This folder is a static reader package for the password-protected site.

## Upload

Upload this whole folder as one unit:

- `index.html`
- `styles.css`
- `spike.js`
- `vendor/page-flip.browser.js`
- `assets/manifest.json`
- `assets/pages/page-001.webp` through `page-068.webp`

Recommended URL:

`/reader/intrepid-dusk-volume-1/`

## Notes

- This version uses 68 optimized WebP content pages at 2200px wide.
- One blank spacer slot is added before Chapter 3 so the chapter opener lands on the right.
- The package is about 66 MB.
- No PDF rendering is required in the browser.
- Keep the original PDFs as master/source files separately.

## Quick Test

After upload, open:

`https://YOUR-SITE/reader/intrepid-dusk-volume-1/`

Confirm:

- Page counter starts at `1 / 68`.
- Next/Previous buttons work.
- Wide windows show a spread.
- Narrow windows show one page.
